# Paper Wall — Conceito do produto

Fonte da verdade do produto (o que é, para quem, e como ganha dinheiro).

## O que é

Micro-SaaS (aplicativo web) que funciona como uma **biblioteca curada de wallpapers para computador**:
- **Estáticos** (imagens)
- **Animados** (vídeos / live wallpapers)

Diferença para bancos de imagem genéricos ou sites como WallpaperAccess/Wallhaven: **recursos criativos** que a concorrência não tem e **foco estético**. A ideia é ajudar quem quer um setup de PC bonito, personalizado e "instagramável", com desktop, ícones e cores combinando.

## Público-alvo

Pessoas que se importam com a estética do próprio setup:
- Gamers
- Criadores de conteúdo
- Entusiastas de "desk setup"
- Devs que passam o dia na tela
- Nichos de estética: minimalista, cyberpunk, quiet luxury, anime, dark academia etc.

## Recursos criativos (candidatos)

> **Lançamento (decidido em 2026-09-13):** **Paletas de cores (3)** + **Múltiplos monitores (6)**. Os dois funcionam só no navegador.
> Os demais ficam para depois. Dinâmicos, live com controle de desempenho e app companion precisam de um app instalado no PC.

1. **Wallpapers dinâmicos**: mudam sozinhos por horário do dia, clima da cidade do usuário ou dia da semana.
2. **Live wallpapers com controle de desempenho**: pausam quando o PC está sob carga, para não travar quem joga.
3. **Paletas de cores**: o usuário escolhe uma paleta (ou extrai de uma imagem de referência) e o sistema sugere wallpapers que combinam, inclusive com ícones e barra de tarefas.
4. **Geração com IA**: a partir de uma descrição ou de uma imagem de referência, para quem quer algo único.
5. **Kits de setup completos**: wallpaper + sugestão de ícones + tema de barra de tarefas + overlays para hardware RGB.
6. **Múltiplos monitores nativo**: imagem única que se estende por 2–3 telas sem cortar elementos importantes.
7. **App companion / extensão**: troca o wallpaper automaticamente no PC, sincronizado com a conta, sem baixar e trocar manualmente.

## Modelo de negócio

**Freemium**
- **Grátis:** biblioteca básica, com marca d'água ou resolução limitada.
- **Assinatura mensal:** acesso ilimitado, vídeos, geração por IA e recursos dinâmicos. São os recursos exclusivos, e por isso o gancho para converter assinantes.

## Nome

**Paper Wall**: inversão de *wallpaper*.
